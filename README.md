# 🧪 통합 단위테스트 관리 프로젝트 (Unit Test Center)

이 프로젝트(`unit_test`)는 워크스페이스 내의 모든 프로젝트(`defect_manage`, `ui_markdown_capture`, `makeyourtoday` 등)에 대한 **단위테스트 계획, 수행, 결과 산출물**을 중앙 집중적으로 관리하기 위한 공간입니다.

## 📂 폴더 구조

- `docs/`: 단위테스트 수행 규칙, 워크플로우, 공통 체크리스트 마스터 문서
- `reports/`: 각 프로젝트별/기능별 단위테스트 결과서 산출물 (Markdown 형식)

## 📜 핵심 거버넌스 문서

단위테스트를 수행하는 모든 에이전트 및 작업자는 아래의 가이드를 엄격히 준수해야 합니다.

1. **[단위테스트 수행 워크플로우](docs/unit_test_workflow.md)**
   - 테스트 대상 분석부터 결과서 도출까지의 표준 절차
2. **[단위테스트 공통 수행 규칙](docs/unit_test_rules.md)**
   - 산출물 포맷(엑셀 컬럼 매핑 기준) 및 항목별 판정 기준(Pass/Fail)
3. **[공통 체크리스트 마스터](docs/common_checklist_master.md)**
   - UI/UX, 반응형, 접근성, 유효성 검사, 보안 등 전 프로젝트에 공통으로 적용되는 필수 점검 항목
4. **[단위테스트 생성 스킬 정의서](../skill_generate_unit_test.md)**
   - 타 PC 및 에이전트 간 이식 가능한 실행 프롬프트 및 스킬 정의

## 🎯 단위테스트 에이전트 스킬 (AI Skills)

본 워크스페이스의 AI 에이전트는 단위테스트 시 다음 스킬을 활용합니다.

- **`Test Planning`**: 프로젝트 문맥과 코드를 분석하여 테스트 케이스(TC)를 도출합니다.
- **`Static Analysis`**: 제공된 HTML/JS/CSS 코드를 기반으로 UI/UX 및 데이터 처리 로직의 결함을 식별합니다.
- **`Reporting`**: 정해진 규격(`DEV_TS_0003`)에 맞춰 결과서(Markdown)를 생성합니다.
